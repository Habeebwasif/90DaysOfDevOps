# Core components of Linux:
- Hardware : The Physical component where OS is installed.
- Kernel : Gives access to the hardware devices i.e. Keyboard,Mouse,Printer etc
- Shell : Acts as an interface between application & kernel.
- Application/GUI: Graphical User Interface for interaction.

# Processes in Linux: 
A process is an instance of a program that is currently running. Ex: cat command. Which is waiting for my input
because everything in linux is either a file/directory or a process. Use top command to list processes.

## Process states: 
- Running- Active process.
- Stopped- Temporarily paused
- Sleeping- Waiting for an event
- Zombie- The process is dead but remains as an entry in the process table.

# 5 Commands to use Daily:
- df -h or free -h - Shows available storage(Hard disk) and available memory in Human readable format.
- sudo - superuserdo which enables permission to have admin access.
- vim - to edit a file.
- systemctl - starting,stopping and checking status of services.
- ssh - Secure shell to connect to remote server.
